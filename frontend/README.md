# Frontend

Application web responsive (smartphone d'abord) avec carte de Douala (Leaflet + OpenStreetMap).

Framework à décider en équipe (React ou Vue). Initialisation suggérée :
```bash
npm create vite@latest . -- --template react
npm install leaflet
```
Écrans de la maquette : inscription, demande de trajet, choix du mode (manuel/autonome),
propositions, carte de l'équipage, tableau de bord organisation.
